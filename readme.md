## 💡 Challenge
Want to take it further? Try this:

- Create an API to serve questions (use a local JSON file)

- Shuffle the questions before sending them to frontend

- Return only 10 random questions per request

- Update the frontend to fetch the questions from the API

- Bonus: Store usernames and scores (no auth needed), we'll use this to build a multiplayer logic in the next session.
